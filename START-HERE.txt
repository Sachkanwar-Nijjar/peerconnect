THIS ENTIRE FOLDER IS THE PROJECT. Keep its contents together.

OPEN THE WEBSITE
1. Open this folder in Windows File Explorer.
2. Double-click OPEN-WEBSITE.cmd.
3. Wait until its black window says READY. Chrome opens automatically.
4. Keep the black window open while using the site.

No commands, Node.js installation or separate database installation are needed
for this Windows x64 ready-to-run bundle. The first opening takes longer while
the folder prepares its own database. It never resets an existing populated DB.
If Chrome is unavailable, the default browser opens instead.

WHAT TO COPY OR GIVE THE TEACHER
Copy the WHOLE PeerConnect-Complete folder. To transfer one file instead, use
PeerConnect-Complete-Windows.zip, then right-click it > Extract All before
running OPEN-WEBSITE.cmd. Do not try to run the app inside the ZIP preview.
On this laptop the folder is already saved; no extraction is necessary.
Choose a short local location such as Documents\PeerConnect-Complete.

node_modules contains installed libraries. runtime contains the bundled Node
program. .next-production is the verified optimized build. These make this
folder much larger than a source-only handoff. Do not delete them for a demo.
The launcher uses development mode so new registrations can use the local
simulated verification link without real email delivery or a paid service.

This is a LOCAL website on this laptop, not a public Internet link. This folder
is specifically prepared for Windows x64. On another operating system, use the
source setup in README.md instead of the Windows launcher.

Keep the database snapshot private. It contains application content and local
demo account password hashes. Active login sessions are not copied.
