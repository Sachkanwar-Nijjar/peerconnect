# 13. Skill-based matching — signature feature

This is the central technical feature of PeerConnect.

Implement the original deterministic matching formula exactly:

**Match Score = (Number of Matching Required Skills / Total Number of Required Skills) × 100**

Example:

Project: Smart Attendance System

Required skills:
- Python
- Machine Learning
- React
- SQL

Candidate A:
Python, Machine Learning, React, SQL
Result: 100%

Candidate B:
Python, Machine Learning, SQL
Result: 75%

Candidate C:
Python, SQL
Result: 50%

Display candidates ranked in descending order of match score.

Each candidate card should show:
- Name
- Avatar
- Department
- Skills
- Match percentage
- Matched skills
- Missing skills
- View profile action

Use visually impressive match indicators and progress bars.

Normalize skill labels consistently.

Do not allow availability, experience, interests, or arbitrary weights to change the original baseline score.

If a project has no suitable matches, display a proper empty state rather than fabricated recommendations.

Do not replace this logic with AI or machine learning.

Write unit tests for exact expected scores and ranking.
