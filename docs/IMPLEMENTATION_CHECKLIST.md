# PeerConnect implementation checklist

The source report and all ten original test cases were read before application code was written. The pasted master prompt supplies the execution instructions; the attached PDF and DOCX supply requirements and expected results.

1. Analyze: extract FR-01–25, BR-01–05, US-01–15 and original detailed TC-01–10; record scope decisions.
2. Foundation: Next.js App Router, TypeScript, shared design system, PostgreSQL/Prisma, secure sessions, verification.
3. Original core: profiles, project/research discovery, deterministic matching, applications, capacity-safe team formation.
4. Communication: private direct messaging, unread state, persistent notifications.
5. Community: categories, text composer, comments, likes, ownership, reports, linked highlighted announcements.
6. Administration: report review/hiding/restoration, account disabling, role assignment and faculty approval.
7. Quality: reproducible fictional fixtures, original detailed acceptance tests, negative authorization tests, build/type/lint/unit/browser checks, responsive visual review, viva documentation.

Execution evidence and outstanding limitations belong in TEST_REPORT.md. This checklist describes planned coverage and is not a claim of passing tests.
